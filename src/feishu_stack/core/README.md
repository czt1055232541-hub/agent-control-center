# core

这个目录放“全项目共用的底层能力”。这些文件通常不直接体现某个页面功能，但很多模块都会依赖它们。

文件说明：

- `settings.py`：最重要的配置入口。负责读取配置文件、默认值、校验、路径解析。
- `models.py`：后端常用数据结构定义，很多接口返回值都会用到这里的模型。
- `process.py`：和本机进程、PID、端口检查、启动/停止辅助有关的工具。
- `status.py`：整理整个系统当前状态，比如 MoonBridge、OpenClaw、Codex 的运行情况。
- `logs.py`：读取日志尾部、聚合日志片段等小工具。
- `log_manager.py`：日志文件路径、日志记录器、日志管理辅助。
- `__init__.py`：包初始化文件。

学习建议：

- 想改配置，先看 `settings.py`。
- 想理解“状态页面的数据从哪来”，看 `status.py`。
- 想定位本机进程启动/停止行为，配合 `process.py` 一起看。
